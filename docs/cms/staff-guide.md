# Updating the website: staff guide

You can update parts of the Oakdene website yourself:

- program days and times
- the team and board pages
- FAQs and testimonials
- the Service Directory
- flyers and information sheets

Your changes are saved as drafts. Simon checks them and puts them live, so you can't break the site.

## Signing in

1. Go to oakdenehouse.org.au/admin/staff/
2. Select Login with GitHub and sign in with your GitHub account.

The first time, GitHub asks you to authorise the Oakdene content editor. Select Authorize.

## Making a change

1. Choose an area on the left, such as Program days and times.
2. Open the item you want to change. Some sections open with a click on the arrow next to their name.
3. Type your change.
4. Select Save at the top. You'll see "Entry saved". This is a draft and isn't live yet.
5. Set Status to In review so Simon knows it's ready to check.

Simon publishes it, and it shows on the website a few minutes later.

To see what's waiting, select Workflow at the top. Your draft stays there until it's published.

## Writing tips

- Write in plain Australian English, in the same warm, practical tone as the rest of the site. Say "people affected by addiction" or "person in recovery", never "addict".
- Email addresses and phone numbers become links by themselves.
- To add a link, type the link text in square brackets followed by the address in round brackets, for example: [our referral form](/services/referral/)
- For bold text, put two stars on each side, for example: **Bring photo ID**
- Testimonials must be real quotes, word for word, used with the person's permission.

## Photos and PDFs

- **Team or board photo:** in the person's entry, select Choose an image, then Upload. Use a clear JPEG photo at least 800 pixels wide.
- **Flyer or information sheet:** in Resources, select Add resource, give it a title, then upload the PDF. The page shows the file size automatically.

## Changed your mind?

Before a draft is published, open it and select Delete unpublished changes. Once a change is live, ask Simon to change it back.

## Need help?

Contact Simon Jarvis. If something on the website looks wrong after a change goes live, tell Simon straight away. Every change is recorded, so it can always be undone.
